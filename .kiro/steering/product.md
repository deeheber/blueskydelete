# Product Overview

**blueskydelete** is a Python automation tool that cleans up old Bluesky social media content.

## Purpose

Automatically deletes posts, reposts, and likes older than a configurable threshold (default: 90 days) to keep your Bluesky feed fresh and manageable.

## Key Features

- **Safe by default**: Dry run mode prevents accidental deletions
- **Flexible configuration**: Customizable date ranges and logging levels
- **Multiple content types**: Handles posts, reposts, and likes
- **Automated scheduling**: GitHub Actions workflow for hands-off operation
- **User-friendly**: Color logging and clear feedback

## Target Users

Bluesky users who want to maintain a clean, recent social media presence without manual content management.

## Safety Philosophy

The tool prioritizes user safety with dry run defaults, clear warnings, and detailed logging to prevent accidental data loss.
